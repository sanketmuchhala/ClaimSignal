# ClaimSignal — Real-Time Claims Triage with Jev

**Status: Actively working on this project right now.**

A TypeScript service for Cloudflare Workers that classifies insurance claims, scores fraud indicators, and routes cases using Jev's typed decisions. Confidence thresholds select automatic triage, LLM fallback, or human review.

Implementation and live-provider validation are in progress. Benchmark results will be published only after real measurements.
